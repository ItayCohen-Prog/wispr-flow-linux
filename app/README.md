# app/

The Wispr Flow repackaging pipeline and the Omarchy Flow Bar plugin. Setup
steps, build instructions and the project overview live in the
[repository README](../README.md); the reference docs start at
[docs/index.md](docs/index.md).

This directory began as a `git subtree` import of the community port
[wispr-flow-linux/wispr-flow-linux](https://github.com/wispr-flow-linux/wispr-flow-linux)
(public domain, Unlicense) and was then cut down to what runs on Omarchy.
